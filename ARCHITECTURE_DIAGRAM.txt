================================================================================
                        GUEST METHOD LAYER
================================================================================

    ┌─────────────────────────────────────────────────────────────┐
    │      freefire/guest_likes_engine.py (GUEST ENGINE)          │
    │                                                             │
    │  Main Function: send_likes_with_guests()                    │
    │    ├─ Load usage data (JSON)                                │
    │    ├─ Filter available guests (unused for target)           │
    │    ├─ Create 20 concurrent tasks (Semaphore)                │
    │    ├─ For each guest: like_with_guest()                     │
    │    ├─ Gather results                                        │
    │    └─ Save usage data (JSON)                                │
    └─────────────────────────────────────────────────────────────┘
         │
         │ For each guest (concurrent)
         ▼
    ┌─────────────────────────────────────────────────────────────┐
    │              like_with_guest() (PER GUEST)                  │
    │                                                             │
    │  1. Check if guest already used for target                  │
    │  2. Create JWT for guest (get_jwt.py)                       │
    │  3. Create encrypted payload (encrypt_like_body.py)         │
    │  4. Send POST to Garena server                              │
    │  5. Mark guest as used for target                           │
    └─────────────────────────────────────────────────────────────┘
         │
         │ HTTP POST
         ▼
    ┌─────────────────────────────────────────────────────────────┐
    │            GARENA SERVERS (Direct Connection)               │
    │                                                             │
    │  • client.ind.freefiremobile.com (IND region)               │
    │  • client.us.freefiremobile.com (US/BR regions)             │
    │  • clientbp.ggblueshark.com (other regions)                 │
    │                                                             │
    │  Endpoint: /LikeProfile                                     │
    │  Auth: Bearer JWT (from guest account)                      │
    │  Body: Encrypted protobuf (uid + region)                    │
    └─────────────────────────────────────────────────────────────┘

================================================================================
                        SUPPORTING MODULES
================================================================================

┌───────────────────────────────────────────────────────────────────────────┐
│                          AUTHENTICATION                                   │
├───────────────────────────────────────────────────────────────────────────┤
│  freefire/get_jwt.py                                                      │
│    • create_jwt(uid, password) → (jwt, region, server_url)               │
│    • Uses: https://loginbp.ggblueshark.com/MajorLogin ✅ (FIXED)         │
│    • Creates JWT for guest accounts                                       │
│    • Returns auth token + region + server URL                            │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│                          ENCRYPTION                                       │
├───────────────────────────────────────────────────────────────────────────┤
│  freefire/encrypt_like_body.py                                            │
│    • create_like_payload(uid, region) → encrypted_bytes                  │
│    • Uses protobuf: ff_proto/send_like_pb2.py                            │
│    • AES-CBC encryption with Garena keys                                 │
│    • Returns binary payload for /LikeProfile                             │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│                          PLAYER INFO                                      │
├───────────────────────────────────────────────────────────────────────────┤
│  freefire/hl_gaming_player_api.py                                         │
│    • get_player_info_hl_gaming(uid, region) → player_info                │
│    • Fetches: name, level, likes, rank, guild                            │
│    • Used for validation and display                                     │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│                          DATA STORAGE                                     │
├───────────────────────────────────────────────────────────────────────────┤
│  freefire/guests_manager/guests_converted.json                            │
│    • 161 guest accounts (UID + password)                                 │
│    • Format: [{"uid": "...", "password": "..."}, ...]                    │
│    • Read-only (never modified)                                          │
│                                                                           │
│  usage_history/guest_usage_by_target.json                                 │
│    • Per-target guest usage tracking                                     │
│    • Format: {target_uid: {used_guests: {guest_uid: timestamp}, ...}}   │
│    • Auto-created on first run                                           │
│    • Thread-safe with async locks                                        │
└───────────────────────────────────────────────────────────────────────────┘

  │    │
  │    ▼

  │    │
  │    ├─► Load usage_history/guest_usage_by_target.json
  │    │     Current: {}
  │    │
  │    ├─► Filter unused guests for "1234567890"
  │    │     Result: 161 available
  │    │
  │    ├─► Create 20 concurrent tasks (first 100 guests)
  │    │    │
  │    │    ▼
  │    │   like_with_guest() × 100 (concurrent)
  │    │    │
  │    │    ├─► get_jwt(guest_uid, guest_pass)
  │    │    │     └─► POST https://loginbp.ggblueshark.com/MajorLogin
  │    │    │           Returns: JWT + region + server_url
  │    │    │
  │    │    ├─► encrypt_like_body(target_uid, region)
  │    │    │     └─► Protobuf + AES encryption
  │    │    │           Returns: Binary payload
  │    │    │
  │    │    ├─► POST https://client.ind.freefiremobile.com/LikeProfile
  │    │    │     Headers: Authorization: Bearer {JWT}
  │    │    │     Body: {encrypted_payload}
  │    │    │     Result: 200 OK
  │    │    │
  │    │    └─► mark_used(target_uid, guest_uid, timestamp)
  │    │
  │    ├─► Gather results: 100 success, 0 failed
  │    │
  │    └─► Save usage_history/guest_usage_by_target.json
  │          Updated: {"1234567890": {"used_guests": {100 entries}, "total_likes": 100}}
  │
  └─► Result: 100 likes sent successfully ✅
