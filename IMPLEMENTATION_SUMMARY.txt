HOW IT WORKS
================================================================================

User Flow:
  /likes 1234567890
    ↓
  Check balance (50 coins required)
    ↓
  Fetch player info (HL Gaming API)
    ↓
  Check available guests for this UID
    ↓
  Deduct coins
    ↓
  ┌─ If ≥50 guests available ────────────┐
  │  Try guest method                     │
  │    ├─ Success (≥50 likes) → DONE ✅   │
  │    └─ Partial/Failed → HL Gaming ⤵    │
  └───────────────────────────────────────┘
  ┌─ If <50 guests available ─────────────┐
  │  Use HL Gaming directly → DONE ✅      │
  └───────────────────────────────────────┘
  ┌─ If both methods fail ────────────────┐
  │  Refund coins + Error message ❌       │
  └───────────────────────────────────────┘

Guest Usage Tracking:
  • File: usage_history/guest_usage_by_target.json
  • Format: {"target_uid": {"used_guests": {"guest_uid": timestamp}, "total_likes": N}}
  • Permanent: Once a guest likes a target, never used again for that target
  • Per-target: Same guest can like different targets

Fallback Triggers:
  • Guest pool exhausted (<50 available)
  • Guest method fails/errors
  • Partial success (<50 likes sent)
